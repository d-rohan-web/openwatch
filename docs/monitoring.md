# Monitoring & dashboards

Four Grafana dashboards (generated by `infrastructure/monitoring/grafana/build_dashboards.py`, JSON in
`infrastructure/monitoring/grafana/dashboards/`):

| Dashboard | Answers |
|---|---|
| **Overview** | Are feeds healthy? How much is live / archived? Visitors and data served today; feed-health table; warnings & errors from the logs |
| **Situation** | How the situation changes over time: active alerts by severity, warnings by source, aircraft and satellites tracked, maritime/airspace notices, outages, quakes |
| **Visitors & traffic** | Unique visitors per hour, top pages, referrers, browsers, status codes, response time, bandwidth and projected monthly egress vs the free 1 GB |
| **Server health** | CPU, memory, swap, disk, network, load: what matters on a 1 GB VM |

One agent, **Grafana Alloy**, scrapes the collector/API metrics and host metrics and ships container logs plus Caddy's
access log. Where it ships depends on the profile:

## On the server → Grafana Cloud (free, nothing extra exposed)

Only Alloy runs on the VM (~80 MB, capped at 192 MB); data goes out to Grafana Cloud's free tier. No new IP, port or
firewall rule.

1. Create a free account at grafana.com and a stack.
2. Collect: Prometheus **remote-write URL** + **instance ID**, Loki **URL** + **user** (stack → Details), and an
   **access-policy token** with `metrics:write` and `logs:write`.
3. In Cloud Shell: `PROJECT=<your-project-id> bash scripts/deploy/grafana-cloud.sh` (prompts; the token is hidden and
   travels over SSH stdin into the VM's `.env`, mode 600).
4. In Grafana Cloud: **Dashboards → New → Import**, upload each JSON from `infrastructure/monitoring/grafana/dashboards/`,
   pick your `grafanacloud-…-prom` and `-logs` data sources.

## Locally → full stack

```bash
docker compose --profile monitoring up -d     # Prometheus, Loki, Alloy, Grafana
open http://localhost:39300                   # admin / GRAFANA_ADMIN_PASSWORD; dashboards are pre-loaded
```

## Editing dashboards

Change `build_dashboards.py`, run `python infrastructure/monitoring/grafana/build_dashboards.py`, re-import (Cloud) or
restart Grafana (local). Data sources are dashboard variables, so the same JSON works everywhere.

## Metrics exported by the collector

`openwatch_fetch_total{feed,result}` · `openwatch_records_total{feed}` · `openwatch_records_stored_total{feed}` ·
`openwatch_live_records{feed}` · `openwatch_live_severity{feed,severity}` · `openwatch_feed_failing{feed}` ·
`openwatch_last_ok_timestamp{feed}` · API: `openwatch_exports_total{format}`
